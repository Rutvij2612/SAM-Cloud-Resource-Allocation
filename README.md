# Stochastic Adaptive Mapping (SAM) Framework for SLA-Aware Cloud Resource Allocation under Workload Uncertainty

This repository contains the implementation of the **Stochastic Adaptive Mapping (SAM)** framework, developed as part of a BTech CSE Semester 7 Research Methodology Seminar (RMS) project. 

## Project Overview

In cloud environments, workload demands fluctuate dynamically, introducing significant uncertainty. Traditional deterministic resource allocation approaches often lead to either over-provisioning (incurring unnecessary costs) or under-provisioning (resulting in Service Level Agreement / SLA violations). 

The **Stochastic Adaptive Mapping (SAM)** framework is a proposed research project designed to model workload uncertainty stochastically and adaptively map resources to meet SLA constraints while optimizing resource utilization.

### Technical Approach & Objectives
- **Workload Forecasting:** Predict CPU and memory demands, utilizing CPU average usage indicators from historical traces.
- **Uncertainty Modeling:** Characterize prediction errors and workload fluctuations stochastically.
- **Resource Allocation Optimization:** Formulate and solve optimization models that balance cost and SLA compliance under uncertainty.
- **Experimental Validation:** Compare multiple forecasting methods and uncertainty models using real-world cloud workload data.

## Dataset

The framework uses a subset/sample of the **Google Cluster Trace 2019**, obtained via Kaggle. The dataset contains detailed usage information for task resources (CPU, memory) across virtual machines, which will be utilized for workload prediction and simulation experiments.
